인증 시험 모드 ​

인증 시험 범위 밖 기능을 숨기고 API 를 막는 모드의 설정과 대상.

인증 시험 모드는 GS 인증 시험 범위 밖의 기능을 화면에서 숨기고, 해당 API 를 403 feature_hidden 으로 막습니다. 숨기는 기능은 6가지입니다.

켜고 끄기 ​

  • 관리자 콘솔 — 「시스템 관리자」 화면의 인증 시험 모드 카드에서 켜고 끕니다. 저장한 값이 환경변수보다 우선합니다.
  • 환경변수 — 관리자가 따로 저장하지 않았으면 GAEA_CERT_PROFILE=1 일 때 켜집니다.
  • API — GET /api/admin/cert-profile 로 상태(enabled·source·envDefault)를 보고, PUT /api/admin/cert-profile 에 { "enabled": true } 를 보내 저장합니다(플랫폼 관리자 전용, 감사 기록).
