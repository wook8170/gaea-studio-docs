describe_view_options ​

조회

set_tab_config 로 조작 가능한 grid/pivot/chart/표시 옵션의 유효 키·enum·설명 카탈로그를 돌려줘요(정적). chartOpts/pivotOpts/displayOpts 를 바꾸기 전에 이 도구로 유효한 옵션명·값을 확인하라. 예: "피벗에서 소계 켜고 상위 10만 보이게 옵션 알려줘" → describe_view_options.

ts
describe_view_options({ area?: "all" | "chart" | "pivot" | "grid" | "value" })
인자형식필수설명
area"all" | "chart" | "pivot" | "grid" | "value"좁혀 볼 영역(기본 all).

get_pivot_result ​

조회

피벗에 표시되는 집계 데이터(모든 소계/총합 레벨 포함)를 컴팩트 JSON 으로 돌려줘요 — AI 에이전트가 피벗 결과를 보고 검증·반복할 때. 탭(projectId+tabId)을 주면 그 탭의 피벗 구성을, 아니면 endpointId + rows/cols/values 를 직접 줘요. 응답 각 행의 g<차원>=1 은 그 차원이 소계로 합쳐졌음을 뜻해요. 예: "지금 이 피벗 결과 보여줘" → get_pivot_result({ projectId, tabId }).

ts
get_pivot_result({ projectId?: string, tabId?: string, endpointId?: string, rows?: string[], cols?: string[], values?: object[], limit?: integer })
인자형식필수설명
projectIdstring탭 기반 조회 시 프로젝트 id.
tabIdstring탭 기반 조회 시 탭 id(그 탭의 rows/cols/values/filters 사용).
endpointIdstring직접 조회 시 엔드포인트 id.
rowsstring[]행 차원(직접 조회).
colsstring[]열 차원(직접 조회).
valuesobject[]측정값(직접 조회).
limitinteger최대 그룹(셀) 행수.

profile_endpoint ​

조회

엔드포인트(표)의 데이터 프로파일을 돌려줘요 — 총 행수, 수치 컬럼별 기술통계(min/max/avg/sum), 차원 컬럼 목록. 리포팅/분석 착수 전 데이터 감을 잡을 때. 예: "이 데이터 프로파일 뽑아줘" → profile_endpoint({ endpointId }).

ts
profile_endpoint({ endpointId: string, filters?: object[] })
인자형식필수설명
endpointIdstring예대상 엔드포인트 id.
filtersobject[]프로파일 전 적용할 필터.

get_column_stats ​

조회

한 컬럼(측정값)의 기술통계를 한 번에 돌려줘요 — 평균·중앙값·표준편차·최소·최대·분위·개수·고유값. /aggregate(groupBy:[])로 전체셋을 한 번에 집계해요(적재 엔드포인트는 정확, 라이브는 중앙값·표준편차·분위가 표본 근사). 예: "매출액 통계 요약해줘" → get_column_stats({ endpointId, field: "매출액" }).

ts
get_column_stats({ endpointId: string, field: string, filters?: object[] })
인자형식필수설명
endpointIdstring예대상 엔드포인트 id.
fieldstring예통계를 낼 컬럼(측정값)명.
filtersobject[]집계 전 적용할 필터.

get_contribution ​

조회

두 기간의 측정값 변화를 요인 차원 값별 증감으로 분해해요(기여도 분석, "왜 변했나"). 총증감·상위 요인(값·기여율%)·워터폴 스텝을 돌려줘요. 서버 /aggregate 로 base/current 를 요인별 전체셋 집계해요. 예: "2025→2026 매출이 왜 늘었어?" → get_contribution({ endpointId, measure:{field:"매출",agg:"sum"}, periodField:"연도", baseKey:"2025", currentKey:"2026", factorField:"지역" }).

ts
get_contribution({ endpointId: string, measure: object, periodField: string, baseKey: string, currentKey: string, factorField: string, filters?: object[], topN?: integer })
인자형식필수설명
endpointIdstring예대상 엔드포인트 id.
measureobject예분해할 측정값 {field, agg}.
periodFieldstring예기간(시간축) 차원 필드명.
baseKeystring예기준(직전) 기간 키 — 예 "2025".
currentKeystring예현재 기간 키 — 예 "2026".
factorFieldstring예증감을 나눠 볼 요인 차원 필드명.
filtersobject[]공통 사전 필터.
topNinteger상위 요인 개수(기본 8, 나머지는 기타로 합산).

explain_change ​

조회

두 기간 간 측정값 변화를 여러 요인 차원에 걸쳐 자동 스캔해 어느 차원이 가장 설명력 있는지 랭킹해요(top1Share 기준, "이 변화 설명해줘"). 기간은 단일 키(baseKey/currentKey) 또는 범위(basePeriod/currentPeriod {from,to}) 중 정확히 하나로 지정하고, dimensions 를 생략하면 후보 차원을 자동 수집해요(최대 6개). 요인 차원을 이미 알면 get_contribution 이 더 가볍어요(호출 1회). 예: "매출이 왜 늘었어?" → explain_change({ endpointId, measure:{field:"매출",agg:"sum"}, periodField:"연도", baseKey:"2025", currentKey:"2026" }).

ts
explain_change({ endpointId: string, measure: object, periodField: string, baseKey?: string, currentKey?: string, basePeriod?: object, currentPeriod?: object, dimensions?: string[], filters?: object[], topN?: integer })
인자형식필수설명
endpointIdstring예대상 엔드포인트 id.
measureobject예분해할 측정값 {field, agg}. agg 가 sum/count 가 아니면 sum 으로 강제하고 agg-coerced caveat 를 알려요.
periodFieldstring예기간(시간축) 차원 필드명.
baseKeystring기준 기간 키(단일 값 모드) — currentKey 와 함께 지정, basePeriod/currentPeriod 와는 배타적.
currentKeystring현재 기간 키(단일 값 모드) — baseKey 와 함께 지정.
basePeriodobject기준 기간 범위 {from,to}(범위 모드) — currentPeriod 와 함께 지정, baseKey/currentKey 와는 배타적.
currentPeriodobject현재 기간 범위 {from,to}(범위 모드) — basePeriod 와 함께 지정.
dimensionsstring[]스캔할 요인 차원(최대 6개). 미지정 시 role=dimension 필드에서 자동 수집(periodField 제외, 앞 6개).
filtersobject[]공통 사전 필터.
topNinteger차원별 상위 요인 개수(기본 8, 나머지는 "기타"로 합산).
