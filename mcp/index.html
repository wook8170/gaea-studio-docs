MCP 서버 ​

Gaea Studio 서버는 MCP(Model Context Protocol) 호스트를 내장하고 있어요. AI 에이전트가 도구 192개(25개 분류)로 데이터 조회·분석 구성·대시보드·공유를 다뤄요.

연결 전에 준비할 것 ​

  1. MCP 주소 — 설치한 서버 주소 뒤에 /api/mcp 를 붙여요(예: https://gaea.example.com/api/mcp). 스튜디오 「내 정보 › MCP 연결」 카드에 실제 주소가 나와요.
  2. 개인 액세스 토큰 — 「내 정보 › 개인 액세스 토큰」에서 발급해요(gpat_ 로 시작). 원문은 발급 직후 한 번만 보여요.
  3. 권한 — 도구는 토큰 주인의 권한으로 실행돼요. 읽기 전용 토큰이면 바꾸는 도구가 403 으로 거절돼요.

확인이 필요한 도구 ​

삭제 · 공유 발급 · 적재처럼 되돌리기 어려운 도구는 confirm 인자를 받아요. confirm 없이 부르면 실행하지 않고 영향 요약만 돌려주고, 같은 인자에 confirm: true 를 더해 다시 부르면 실행해요.

폐쇄망 ​

HTTP 연결이 막힌 환경에서는 내 PC 에서 gaea-mcp 를 stdio 로 띄워요(아래 「stdio(로컬)」). GAEA_SERVER 는 서버 주소, GAEA_TOKEN 은 개인 액세스 토큰이에요.

클라이언트별 연결 ​

Claude Code ​

터미널에서 한 번 실행하면 등록돼요.

sh
claude mcp add --transport http gaea https://gaea.example.com/api/mcp --header "Authorization: Bearer <PAT>"

Claude Desktop ​

claude_desktop_config.json 의 mcpServers 에 넣어요(mcp-remote 브리지 경유).

json
{
  "mcpServers": {
    "gaea": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://gaea.example.com/api/mcp",
        "--header",
        "Authorization: Bearer <PAT>"
      ]
    }
  }
}

Cursor · Windsurf ​

mcp.json(Cursor: .cursor/mcp.json · Windsurf: ~/.codeium/windsurf/mcp_config.json) 에 넣어요.

json
{
  "mcpServers": {
    "gaea": {
      "url": "https://gaea.example.com/api/mcp",
      "headers": {
        "Authorization": "Bearer <PAT>"
      }
    }
  }
}

stdio(로컬) ​

내 PC 에서 gaea-mcp 프로세스를 직접 띄울 때. HTTP 가 막힌 폐쇄망 경로용이에요.

sh
GAEA_SERVER=https://gaea.example.com GAEA_TOKEN=<PAT> npx gaea-mcp

원시 HTTP ​

붙기 전에 주소·토큰만 먼저 확인할 때(initialize 한 번).

sh
curl -sS -X POST https://gaea.example.com/api/mcp \
  -H "Authorization: Bearer <PAT>" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"curl","version":"1.0"}}}'
