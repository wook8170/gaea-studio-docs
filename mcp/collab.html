share_view ​

확인 필요(confirm) 변경

저장된 보기(view)의 외부 공개 링크를 발급해요 — 발급 시점의 상위 100행이 스냅샷으로 고정되며, 이후 원본이 바뀌어도 링크 내용은 갱신되지 않아요. 그리드/피벗/차트 중 공유할 표현을 지정할 수 있고, 차트면 종류도 함께 지정 가능(미지정=보기에 저장된 표현 그대로). maskFields 로 공유본에서 특정 컬럼 값을 '***' 로 가릴 수 있어요. 외부공유는 뷰 소유자(또는 workspace 보기는 editor 이상)만 가능해요(서버 강제). 워크스페이스 공유 정책(익명 링크 금지·비밀번호 필수·최대 만료일)에 걸리면 400 share_policy_violation 이 나와요 — 그때는 get_share_policy 로 규칙을 읽고 인자를 맞춰요. 만료 프리셋(7일/30일/90일)은 호출측이 실제 날짜로 계산해 expiresAt 에 실어요. 열람 화면의 내보내기 허용(allowExport)은 대시보드 공유(share_dashboard)에만 있는 축이라 여기서는 받지 않아요. confirm 없이 부르면 대상·만료·비밀번호·표현·마스킹 요약만 반환하고 실행하지 않아요. 결과의 링크 토큰은 가려져요([REDACTED]) — 공유 id 만 돌려주고, 링크는 사용자가 공유 화면에서 복사해요. 예: "이 보기 외부에 차트(막대)로 공유해줘, 7일 뒤 만료" → share_view({ viewId, expiresAt: "2026-07-21T00:00:00+09:00", viewModeOverride: "chart", chartTypeOverride: "bar" }) 후 confirm:true.

ts
share_view({ viewId: string, expiresAt?: string | null, password?: string | null, viewModeOverride?: "grid" | "pivot" | "chart", chartTypeOverride?: "bar" | "stack" | "bullet" | "pareto" | "radar" | "gauge" | "line" | "stepLine" | "area" | "themeRiver" | "pie" | "doughnut" | "rose" | "treemap" | "sunburst" | "histogram" | "scatter" | "bubble" | "funnel" | "waterfall" | "swimlane" | "gantt", maskFields?: string[], confirm?: boolean })
인자형식필수설명
viewIdstring예공유할 보기 id.
expiresAtstring | null만료 시각 — 시간대 정보가 포함된 ISO 문자열이어야 해요(예: "2026-07-21T00:00:00+09:00" 또는 "2026-07-20T15:00:00Z"). 오프셋 없는 값("", "2026-07-21T00:00")은 거절돼요. null/미지정=무기한(워크스페이스 정책에 maxExpiryDays 가 걸려 있으면 무기한·상한 초과는 400 share_policy_violation).
passwordstring | null열람 비밀번호. null/미지정=비밀번호 없음(정책 requirePassword 면 필수).
viewModeOverride"grid" | "pivot" | "chart"공유 시 표현을 그리드/피벗/차트 중 하나로 지정(공유 표현 — 탭 뷰 모드와 별개). 미지정=보기에 저장된 표현 그대로.
chartTypeOverride"bar" | "stack" | "bullet" | "pareto" | "radar" | "gauge" | "line" | "stepLine" | "area" | "themeRiver" | "pie" | "doughnut" | "rose" | "treemap" | "sunburst" | "histogram" | "scatter" | "bubble" | "funnel" | "waterfall" | "swimlane" | "gantt"viewModeOverride="chart" 일 때의 차트 종류(예: bar, line, pie). 미지정 시 보기에 저장된 차트 종류 사용.
maskFieldsstring[]공유본에서 값을 '***' 로 가릴 컬럼명 목록(차원/텍스트 컬럼만). 이 보기의 행/열/측정값/필터에 쓰이는 컬럼이나 없는 컬럼을 주면 422 로 거절돼요(축이 붕괴하거나 집계가 파손되므로).
confirmboolean

share_dashboard ​

확인 필요(confirm) 변경

대시보드(프로젝트) 화면 전체의 외부 공개 링크를 발급해요 — share_view 의 대시보드 짝이에요. mode=snapshot(기본)은 발급 시점의 위젯 화면을 동결하고, live 는 열람할 때마다 다시 질의해요. allowExport 는 열람 화면에서 내보내기·인쇄를 허용할지로, 미지정이면 워크스페이스 공유 정책 기본값을 따라요(출하 기본은 불허 — 공개 링크에서 원본 반출은 명시적 선택이어야 해요). editor 이상만 발급할 수 있고(서버 강제), 위젯이 하나도 없는 대시보드는 400 empty_dashboard 로 거절돼요. 워크스페이스 공유 정책(익명 링크 금지·비밀번호 필수·최대 만료일)에 걸리면 400 share_policy_violation 이 나와요 — 그때는 get_share_policy 로 규칙을 읽고 인자를 맞춰요. confirm 없이 부르면 위젯 수·기존 활성 링크 수와 요청 요약만 반환하고 발급하지 않아요. 결과의 링크 토큰은 가려져요([REDACTED]) — 공유 id 만 돌려주고, 링크는 사용자가 공유 화면에서 복사해요. 예: "이 대시보드 링크 만들어 줘, 30일 뒤 만료" → share_dashboard({ dashboardId, expiresAt: "2026-10-13T00:00:00+09:00" }) 후 confirm:true.

ts
share_dashboard({ dashboardId: string, expiresAt?: string | null, password?: string | null, mode?: "snapshot" | "live", allowExport?: boolean, confirm?: boolean })
인자형식필수설명
dashboardIdstring예공유할 대시보드(프로젝트) id.
expiresAtstring | null만료 시각 — 시간대 정보가 포함된 ISO 문자열이어야 해요(예: "2026-07-21T00:00:00+09:00" 또는 "2026-07-20T15:00:00Z"). 오프셋 없는 값("", "2026-07-21T00:00")은 거절돼요. null/미지정=무기한(워크스페이스 정책에 maxExpiryDays 가 걸려 있으면 무기한·상한 초과는 400 share_policy_violation).
passwordstring | null열람 비밀번호. null/미지정=비밀번호 없음(정책 requirePassword 면 필수).
mode"snapshot" | "live"snapshot=발급 시점 화면 동결(기본) · live=열람할 때마다 다시 질의(항상 최신).
allowExportboolean열람 화면의 내보내기·인쇄 허용 여부. 미지정=워크스페이스 공유 정책 defaultAllowExport(출하 기본 불허).
confirmboolean

get_share_access_logs ​

조회

공유 링크의 접근 이력(언제·어느 IP·성공/실패)을 최근 순으로 돌려줘요 — 「이 링크 누가 열어봤어?」의 답이에요. 공개 링크는 로그인 주체가 없어 남는 것은 IP 대역과 결과뿐이고(응답 identityScope="anonymous"), IP 는 워크스페이스 공유 정책 maskAccessIp(기본 켬)면 마지막 옥텟이 가려진 값이에요(응답 ipMasked 로 알 수 있어요). editor 이상(서버 강제). 공유 id 는 list_shares / list_dashboard_shares 로 확인해요. 예: "이 공유 링크 누가 열어봤어?" → get_share_access_logs({ shareId, kind: "dashboard" }).

ts
get_share_access_logs({ shareId: string, kind?: "view" | "dashboard" })
인자형식필수설명
shareIdstring예대상 공유 링크 id(list_shares / list_dashboard_shares 로 확인).
kind"view" | "dashboard"공유 종류 — 'view'(저장된 보기 공유, 기본) | 'dashboard'(대시보드 화면 공유). 링크를 어느 도구로 발급했는지에 맞춰요(share_view → view, share_dashboard → dashboard).

invite_member ​

확인 필요(confirm) 변경

이메일로 워크스페이스에 멤버를 초대해요 — 실제 이메일이 발송돼요(SMTP 미설정 시 발송 없이 로그만 남아요. 아직 가입하지 않은 이메일의 초대 링크는 보안상 응답에 실리지 않으므로(메일이 유일 경로) 그런 환경에서는 add_member 로 임시 비밀번호를 발급해요). role=editor(기본)|viewer. confirm 없이 부르면 대상 요약만 반환. 예: "wook@example.com 을 editor 로 초대해줘" → invite_member({ workspaceId, email: "wook@example.com", role: "editor" }) 후 confirm:true.

ts
invite_member({ workspaceId: string, email: string, role?: "editor" | "viewer", confirm?: boolean })

emailstring예초대할 이메일.
role"editor" | "viewer"부여할 역할(기본 editor).
confirmboolean

add_member ​

확인 필요(confirm) 변경

이메일 발송 없이 워크스페이스에 멤버를 즉시 추가해요(폐쇄망용) — owner 전용. 신규 계정이면 서버가 임시 비밀번호를 발급해요 — 원문은 에이전트 결과에 실리지 않아요([REDACTED]). 사용자에게는 멤버 화면에서 그 멤버의 「초기화」로 임시 비밀번호를 화면으로 받아 전달하라고 안내해요. confirm 없이 부르면 대상 요약만 반환. 예: "홍길동(hong@example.com)을 viewer 로 추가해줘" → add_member({ workspaceId, name: "홍길동", email: "hong@example.com", role: "viewer" }) 후 confirm:true.

ts
add_member({ workspaceId: string, name: string, email: string, role?: "editor" | "viewer", confirm?: boolean })

workspaceIdstring예대상 워크스페이스 id.
namestring예멤버 이름(신규 계정 생성 시 사용).
emailstring예멤버 이메일.
role"editor" | "viewer"부여할 역할(기본 editor).
confirmboolean

reset_member_password ​

멤버의 비밀번호를 새 임시 비밀번호로 초기화해요(owner 전용, 서버 강제) — 최초 로그인 시 변경이 강제돼요. 다른 owner 의 비밀번호는 초기화할 수 없어요(본인 제외, 서버가 403). 새 임시 비밀번호 원문은 에이전트 결과에 실리지 않아요([REDACTED]) — 원문이 필요하면 사용자가 멤버 화면의 「초기화」로 직접 받아요. confirm 없이 부르면 대상 요약만 반환. 예: "이 멤버 비밀번호 초기화해줘" → reset_member_password({ workspaceId, userId }) 후 confirm:true.

ts
reset_member_password({ workspaceId: string, userId: string, confirm?: boolean })

workspaceIdstring예대상 워크스페이스 id.
