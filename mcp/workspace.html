변경

ts
create_workspace({ name: string, confirm?: boolean })

confirmboolean

add_favorite ​

변경

항목을 즐겨찾기에 추가해요(멱등 — 이미 있으면 그대로). kind=project|overview|dashboard|datasource|view 별로 targetId 가 가리키는 대상이 달라요(project/overview/dashboard=프로젝트 id, datasource=데이터소스 id, view=보기 id). projectId 는 항상 그 대상이 속한 프로젝트 id(즐겨찾기 그룹핑용), label 은 표시 이름. 예: "이 프로젝트 즐겨찾기 해줘" → add_favorite({ kind: "project", targetId: "proj-1", projectId: "proj-1", label: "매출 분석" }).

ts
add_favorite({ kind: "project" | "overview" | "dashboard" | "datasource" | "view", targetId: string, projectId: string, label: string })
인자형식필수설명
kind"project" | "overview" | "dashboard" | "datasource" | "view"예즐겨찾기 종류.
targetIdstring예대상 id(kind 별로 다름).
projectIdstring예대상이 속한 프로젝트 id.
labelstring예표시 이름.

조회

import_openapi_datasource ​

확인 필요(confirm) 조회

OpenAPI 3.x 스펙(url 또는 raw JSON)을 읽어 baseUrl 과 등록 가능한(GET) 엔드포인트 후보 목록을 돌려줘요 — 이 호출 자체는 데이터소스를 등록하지 않아요(후속으로 register_datasource 사용). source 는 { url } 또는 { raw }(스펙 JSON 원문) 중 하나. YAML 스펙은 지원하지 않아요(JSON만). confirm 없이 부르면 요약만 반환해요(외부 URL 로 나가는 조회이므로). 예: "이 OpenAPI 스펙에서 데이터소스 후보 뽑아줘" → import_openapi_datasource({ source: { url: "https:/api.example.com/openapi.json" } }) 후 confirm:true.

ts
import_openapi_datasource({ source: object, insecureTls?: boolean, confirm?: boolean })
인자형식필수설명
sourceobject예
insecureTlsbooleanTLS 인증서 검증 건너뛰기(자체서명 등).
confirmboolean
