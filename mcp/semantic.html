list_metrics ​

조회

엔드포인트의 명명된 재사용 측정값(metric) 목록을 돌려줘요(공유 metric 전부 + 본인 private). 예: "이 표에 정의된 측정값 뭐 있어?" → list_metrics({ endpointId }).

ts
list_metrics({ endpointId: string })
인자형식필수설명
endpointIdstring예대상 엔드포인트 id.

create_metric ​

변경

엔드포인트에 재사용 측정값(metric)을 만들어요. kind="simple"(기본, field+agg 필요) 또는 "calc"(expression 필요 — 예: "sum(amount)/sum(qty)". 문법·함수 목록은 get_metric_expression_syntax). format=default|currency|millions|percent, visibility=workspace(공유·기본)|private(개인). 같은 이름이 이미 있으면 서버가 거부(409). 예: "매출합계 측정값 만들어줘" → create_metric({ endpointId, name: "매출합계", field: "amount", agg: "합계" }). 예: "객단가 = 매출/수량" → create_metric({ endpointId, name: "객단가", kind: "calc", expression: "sum(amount)/sum(qty)" }).

ts
create_metric({ endpointId: string, name: string, kind?: "simple" | "calc", field?: string, agg?: string, expression?: string, format?: "default" | "currency" | "millions" | "percent", visibility?: "workspace" | "private" })
인자형식필수설명
endpointIdstring예측정값을 정의할 엔드포인트 id.
namestring예측정값 이름(엔드포인트 내 고유).
kind"simple" | "calc"simple=field+agg, calc=expression(기본 simple).
fieldstring집계할 컬럼(simple 필수).
aggstring집계 방식(simple 필수; sum·avg 또는 한글 "합계" 등).
expressionstring계산식(calc 필수; 화이트리스트 식). 문법·함수 목록은 get_metric_expression_syntax 로 먼저 확인하라.
format"default" | "currency" | "millions" | "percent"표시 형식(선택).
visibility"workspace" | "private"공개 범위(기본 workspace).

update_metric ​

변경

측정값(metric)을 수정해요 — 준 필드만 갱신돼요. 생성자 또는 owner 만 가능(서버 강제). 예: "매출합계 표시형식을 통화로" → update_metric({ metricId, format: "currency" }).

ts
update_metric({ metricId: string, name?: string, kind?: "simple" | "calc", field?: string, agg?: string, expression?: string, format?: "default" | "currency" | "millions" | "percent", visibility?: "workspace" | "private" })
인자형식필수설명
metricIdstring예수정할 측정값 id.
namestring새 이름.
kind"simple" | "calc"종류 변경(simple↔calc).
fieldstring집계 컬럼(simple).
aggstring집계 방식(simple).
expressionstring계산식(calc). 문법·함수 목록은 get_metric_expression_syntax 로 먼저 확인하라.
format"default" | "currency" | "millions" | "percent"표시 형식.
visibility"workspace" | "private"공개 범위.

get_metric_expression_syntax ​

조회

calc 측정값(create_metric/update_metric 의 expression)이 쓰는 계산식 문법과 사용 가능한 함수 전체 목록(집계·행 레벨)을 돌려줘요. expression 을 쓰기 전에 먼저 이 도구로 문법·함수를 확인하라(추측 금지 — 허용되지 않은 함수는 파스 오류가 돼요). 서버 호출 없는 정적 도구. 예: "계산식에서 어떤 함수 써?" → get_metric_expression_syntax.

ts
get_metric_expression_syntax({  })

set_field_meta ​

확인 필요(confirm) 변경

엔드포인트 컬럼의 역할(role: dimension=차원 / measure=측정값)·표시명(label)·표시 방식(renderer)을 수정해요. role 이 잘못되면 피벗의 값/차원 배치가 어긋나므로 주의해서 바꿔요(예: 숫자 코드 컬럼을 measure 로 두면 피벗 값칸으로 감). label 을 null 또는 빈 문자열로 주면 표시명을 지워 원래 컬럼명으로 되돌려요. renderer 는 셀 표시 방식(kind: image=이미지 / link=링크 / badge=배지 / bar=바 / sparkline=스파크라인 / progress=진행률 / boolean=체크 / rating=별점 / swatch=색상 / iconset=아이콘 / tags=태그 / markdown=마크다운 / qr=QR / range=범위 / gallery=갤러리 / video=비디오 / filechip=파일 / select=선택). renderer=null 이면 기본 표시로 되돌려요. select 는 허용값 목록(options)을 선언하는 kind 로, 목록 밖 값을 그리드에서 위반 표시해요(범주값 오타 발견용). datasourceId 는 list_tree(각 데이터소스 id)로 확인하고, endpointId 는 그 데이터소스가 소유한 엔드포인트여야 해요. confirm 없이 부르면 변경 전 현황(현재 role/label)을 요약해 돌려주고 실행하지 않아요. 예1: "region 컬럼을 차원으로, 표시명 지역" → set_field_meta({ datasourceId, endpointId, fields: [{ name: "region", role: "dimension", label: "지역" }] }) 후 confirm: true. 예2: "상품이미지 컬럼을 썸네일로 보여줘" → set_field_meta({ datasourceId, endpointId, fields: [{ name: "thumb_url", renderer: { kind: "image", height: 40 } }] }) 후 confirm: true.

ts
set_field_meta({ datasourceId: string, endpointId: string, fields: object[], confirm?: boolean })
인자형식필수설명
datasourceIdstring예엔드포인트가 속한 데이터소스 id(list_tree 로 확인).
endpointIdstring예컬럼을 수정할 엔드포인트 id.
fieldsobject[]예수정할 컬럼 목록.
confirmboolean

get_data_catalog ​

조회

데이터소스 하위 전체(데이터소스 자신 + 엔드포인트 + 필드)의 데이터 카탈로그 항목(설명·태그·담당자)을 돌려줘요. 「이 표/이 컬럼이 뭐 하는 거야」에 답할 때 describe_endpoint(구조·컬럼 타입)와 함께 읽어요 — 카탈로그 설명은 그 조직이 직접 적은 공식 설명이고, 담당자(steward)는 질문을 보낼 사람이에요. 항목은 «사람이 적은 것»만 있어요(설명이 없는 자산은 아예 행이 없어요). 워크스페이스 멤버면 읽을 수 있어요(서버 강제). 예: "이 데이터소스 표들 뭐 하는 것들인지 설명 좀" → get_data_catalog({ datasourceId }).

ts
get_data_catalog({ datasourceId: string })
인자형식필수설명
datasourceIdstring예대상 데이터소스 id.

set_catalog_entry ​

변경

데이터 자산의 카탈로그 항목(설명·태그·담당자)을 저장해요 — 대상은 endpointId·fieldName 을 어디까지 주는지로 갈려요: 둘 다 없으면 데이터소스, endpointId 만 주면 엔드포인트, 둘 다 주면 필드. 준 축만 갱신돼요(서버는 전체 치환이지만 이 도구가 먼저 현재 항목을 읽어 생략한 축을 그대로 다시 실어 줘요). 지우려면 명시적으로 빈 값을 줘요(description: null · tags: []). 설명은 500자까지(초과 400), 태그는 최대 10개·각 24자(넘으면 서버가 잘라 저장), 담당자는 그 워크스페이스의 활성 멤버여야 해요(아니면 400). 세 축이 모두 비면 항목 자체가 지워져요. editor 이상이 필요해요(서버 강제 — 읽기는 member). 없는 컬럼명을 주면 404. 예: "고객 테이블에 '월별 결제 원장'이라고 설명 달고 태그 '매출' 붙여줘" → set_catalog_entry({ datasourceId, endpointId, description: "월별 결제 원장", tags: ["매출"] }).

ts
set_catalog_entry({ datasourceId: string, endpointId?: string, fieldName?: string, description?: string | null, tags?: string[], stewardUserId?: string | null })
인자형식필수설명
datasourceIdstring예대상이 속한 데이터소스 id(현재 값을 읽어 부분 갱신하는 데도 써요).
endpointIdstring엔드포인트/필드 대상일 때의 엔드포인트 id(생략=데이터소스 자신이 대상).
fieldNamestring필드 대상일 때의 원본 컬럼명(표시명 아님). endpointId 와 함께 줘요.
descriptionstring | null공식 설명(최대 500자). null/빈 문자열=설명 지움. 생략=현재 값 유지.
tagsstring[]태그 목록(최대 10개, 각 24자 — 서버가 공백 정리·대소문자 무시 중복 제거). []=태그 지움. 생략=현재 값 유지.
stewardUserIdstring | null담당자 사용자 id(그 워크스페이스 활성 멤버만 — list_members 로 찾아요). null=담당자 지움. 생략=현재 값 유지.

get_glossary ​

조회

워크스페이스의 비즈니스 용어집(조직이 쓰는 말의 정의 · 동의어 · 그 말에 연결된 데이터 자산)을 돌려줘요. 「활성 고객이 뭐야」 「가동률 기준이 뭐지」처럼 말의 뜻을 묻는 질문의 정본이에요 — get_data_catalog(자산 1건의 설명·담당자)와 다른 것이고 둘 다 「그 조직이 직접 적은」 값이에요. 한 용어는 여러 자산에 걸쳐요(assets[] — 데이터소스/엔드포인트/필드). 사용자가 쓴 말이 용어가 아니라 동의어일 수 있으므로 term 만이 아니라 synonyms 까지 대조해라. 워크스페이스 멤버면 읽을 수 있어요(서버 강제). 예: "활성 고객 기준이 뭐야?" → get_glossary({ workspaceId }) 후 term/synonyms 대조.

ts
get_glossary({ workspaceId: string })
인자형식필수설명
workspaceIdstring예대상 워크스페이스 id.
