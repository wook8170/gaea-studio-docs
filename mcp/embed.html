get_embed_snippet ​

조회

엔드포인트 하나 또는 프로젝트 대시보드(위젯 전체)를 외부 웹페이지에 읽기전용 iframe 으로 삽입하는 임베딩 스니펫(HTML)과 임베딩 URL 을 만들어줘요. target 으로 대상을 골라요: "endpoint"(기본값, 엔드포인트 하나 — 그리드/피벗/차트 뷰 1개) 또는 "dashboard"(프로젝트 대시보드에 배치된 위젯 전체를 배치 그대로 통째로). 이 도구는 키를 발급하지 않는다 — 임베딩 키(gpat_…)는 워크스페이스 설정 > 액세스 키에서 소유자(owner)가 직접 발급해야 하며(endpoint 대상은 엔드포인트 스코프, dashboard 대상은 프로젝트 스코프로), 그 키를 key 로 넘기면 완성된 스니펫을, 넘기지 않으면 <EMBED_KEY> 자리표시자를 넣어줘요. endpoint 대상은 view(저장된 보기 id)·mode(grid|pivot|chart) 도 지정할 수 있어요(dashboard 대상은 위젯마다 이미 자기 보기를 가지므로 view/mode 를 쓰지 않아요). theme(dark|light)·width·height 로 표현/크기를 지정할 수 있어요. origin(내 배포 주소, 예 https:/gaea.example.com)을 넘기면 완성 URL 을, 없으면 <YOUR_ORIGIN> 자리표시자를 써요. 예1: "이 엔드포인트를 우리 사이트에 차트로 임베딩하고 싶어" → get_embed_snippet({ endpointId, mode: "chart", origin: "https:/gaea.example.com" }). 예2: "이 프로젝트 대시보드를 통째로 파트너 포털에 심고 싶어" → get_embed_snippet({ target: "dashboard", projectId, origin: "https:/gaea.example.com" }).

ts
get_embed_snippet({ target?: "endpoint" | "dashboard", endpointId?: string, projectId?: string, key?: string, view?: string, mode?: "grid" | "pivot" | "chart", signed?: boolean, theme?: "dark" | "light", width?: string, height?: string, origin?: string })
인자형식필수설명
target"endpoint" | "dashboard"임베딩 대상. "endpoint"(기본값) = 엔드포인트 하나(그리드/피벗/차트 뷰 1개). "dashboard" = 프로젝트 대시보드에 배치된 위젯 전체를 배치 그대로 통째로.
endpointIdstring임베딩할 엔드포인트 id. target="endpoint"(기본값)일 때 필수.
projectIdstring임베딩할 프로젝트 id. target="dashboard"일 때 필수 — 그 프로젝트의 대시보드 위젯 전체를 심어요.
keystring임베딩 키(gpat_…, purpose=embed). endpoint 대상은 엔드포인트 스코프, dashboard 대상은 프로젝트 스코프로 발급된 키여야 해요. 넘기면 완성된 스니펫, 없으면 자리표시자. 이 도구가 발급하지 않아요.
viewstring저장된 보기(view) id — target="endpoint"에서만 쓰여요(미지정=엔드포인트 기본). dashboard 대상은 무시돼요.
mode"grid" | "pivot" | "chart"표시 모드 덮어쓰기(grid|pivot|chart) — target="endpoint"에서만 쓰여요. dashboard 대상은 무시돼요.
signedboolean서명 임베딩(HMAC 단명 토큰) 스니펫을 만들어요. true 면 장수명 키(?key=) 대신 ?t=<SIGNED_TOKEN> 를 써요 — 호스트 백엔드가 세션마다 embed 키의 signing_secret 으로 payload 를 HMAC 서명해 만든 단명 토큰(gset_…). 이 도구는 서명하지 않는다(payload 스키마·서명법 안내만). 기본(false)=현행 ?key=(하위호환).
theme"dark" | "light"임베딩 테마(dark|light). 미지정=뷰어 OS/저장값 자동. 두 대상 공통.
widthstringiframe 너비(CSS 값, 예: "100%"·"800px"). 기본 "100%".
heightstringiframe 높이(CSS 값, 예: "600px"). 기본 "600px".
originstring내 Gaea 배포 오리진(예: https:/gaea.example.com). 미지정 시 <YOUR_ORIGIN> 자리표시자.

get_export_security ​

조회

워크스페이스의 내보내기 보안 정책(보안등급 라벨·수신자표기·시각표기·화면 워터마크)을 돌려줘요. null 이면 미설정(스탬프/오버레이 없음, 산출물 바이트 동일). set_export_security 로 바꾸기 전 현재값 확인용. 예: "이 워크스페이스 내보내기 보안 정책 어떻게 돼 있어?" → get_export_security({ workspaceId }).

ts
get_export_security({ workspaceId: string })
인자형식필수설명
workspaceIdstring예대상 워크스페이스 id.

set_export_security ​

확인 필요(confirm) 변경

워크스페이스의 내보내기 보안 정책을 설정하거나 해제해요(owner 전용, 서버 강제). enabled/grade/showRecipient/showTimestamp/screenWatermark 를 지정하면 PDF·Excel 산출물에 보안등급 라벨·수신자·시각 스탬프가, 임베딩 화면에는 대각선 워터마크가 표시돼요. unset:true 로 부르면 정책을 해제해 산출물이 현행과 바이트 동일해져요. 표시 기능일 뿐 완전한 DRM 이 아니다(오버레이·스탬프는 제거·우회 가능). confirm 없이 부르면 요약만 반환. 예1: "내보내기에 '대외비' 라벨과 화면 워터마크 켜줘" → set_export_security({ workspaceId, enabled: true, grade: "대외비", showRecipient: true, showTimestamp: true, screenWatermark: true }) 후 confirm:true. 예2: "내보내기 보안 정책 해제" → set_export_security({ workspaceId, unset: true }) 후 confirm:true.

ts
set_export_security({ workspaceId: string, unset?: boolean, enabled?: boolean, grade?: string, showRecipient?: boolean, showTimestamp?: boolean, screenWatermark?: boolean, confirm?: boolean })
인자형식필수설명
workspaceIdstring예대상 워크스페이스 id.
unsetbooleantrue 면 정책을 해제(미설정으로 되돌림, 산출물 바이트 동일). 지정 시 나머지 정책 필드는 무시.
enabledboolean정책 적용 여부(false 면 저장돼 있어도 스탬프/오버레이 미표시). unset 이 아니면 필수.
gradestring보안 등급 라벨(최대 50자, 예 '대외비'·'내부용'). unset 이 아니면 필수.
showRecipientboolean내보낸 사용자 이름을 산출물에 함께 찍을지(반출 추적).
showTimestampboolean생성 시각을 스탬프/오버레이에 포함할지.
screenWatermarkboolean임베딩(iframe) 화면에 대각선 워터마크 오버레이를 표시할지.
confirmboolean

build_kiosk_url ​

조회

프로젝트 대시보드를 TV/상황판(키오스크) 모드로 순환 상영하는 임베딩 URL 을 조립해요(순수 조립, 서버 호출 없음). projectId 를 기본 대시보드로, rotate 에 다른 대시보드 id 들을 주면 순환(체류시간마다 다음으로) 상영해요. 키오스크 순환은 반드시 다중 대시보드로 스코프된 임베딩 키가 필요하다 — 서명(gset_) 토큰은 단일 리소스라 순환할 수 없어요(워크스페이스 설정 → 임베딩에서 owner 가 projectIds 를 여러 개 넣어 발급 — 키 발급은 UI 전용). key(임베딩 키)를 주면 완성 URL 을, 없으면 <EMBED_KEY> 자리표시자를, origin(내 배포 주소)을 주면 완성 URL 을, 없으면 <YOUR_ORIGIN> 자리표시자를 써요. interval(체류초 {15,30,60,120,300} 기본60)·reload(소프트리로드분 {60,180,360,720,0=끔} 기본360)·refresh(자동새로고침초 {5,10,30,60,300,0=끔} 기본60)·hideFilters(기본 숨김)·theme(dark|light, 미지정=뷰어 자동) 를 지정할 수 있어요(순환 최대 12개). 예: "로비 TV 에 이 대시보드 3개를 60초씩 순환" → build_kiosk_url({ projectId: "p1", rotate: ["p2","p3"], key: "gpat_…", origin: "https:/tv.example.com", interval: 60 }).

ts
build_kiosk_url({ projectId: string, rotate?: string[], key?: string, origin?: string, interval?: number, reload?: number, refresh?: number, hideFilters?: boolean, theme?: "dark" | "light" })
인자형식필수설명
projectIdstring예기본(선두) 대시보드 프로젝트 id.
rotatestring[]함께 순환 상영할 다른 대시보드 id 목록(선두 포함 최대 12개). 다중 대시보드 임베딩 키 필요.
keystring임베딩 키(gpat_…, purpose=embed·다중 projectIds 스코프). 미지정 시 <EMBED_KEY> 자리표시자.
originstring내 Gaea 배포 오리진(예 https:/tv.example.com). 미지정 시 <YOUR_ORIGIN> 자리표시자.
intervalnumber대시보드당 체류 시간(초). 허용집합 {15,30,60,120,300}, 미지정=60.
reloadnumber소프트 리로드 주기(분). 허용집합 {60,180,360,720,0=끔}, 미지정=360.
refreshnumber자동 새로고침 주기(초). 허용집합 {5,10,30,60,300,0=끔}, 미지정=60.
hideFiltersboolean필터바 숨김 여부. 기본 숨김(true) — false 로 주면 필터바를 다시 노출해요.
theme"dark" | "light"임베딩 테마(dark|light). 미지정=뷰어 OS/저장값 자동. 벽면 화면에 고정할 때 지정해요.
