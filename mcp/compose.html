add_measure ​

변경

탭의 값(측정값) 목록에 측정값 1개를 추가해요 — 기존 값을 통째로 교체하지 않고 1개만 더해요. 같은 field+agg 측정값이 이미 있으면 중복 추가하지 않고 그 사실을 알려요. agg 는 한글 라벨("합계"·"평균"·"개수" 등)도 가능. 예: "매출 합계를 값에 추가해줘" → add_measure({ projectId, tabId, field: "amount", agg: "합계" }).

ts
add_measure({ projectId: string, tabId: string, field: string, agg: string, label?: string, format?: "default" | "currency" | "millions" | "percent", display?: "value" | "percentRow" | "percentCol" | "percentTotal" | "rank" })
인자형식필수설명
projectIdstring예탭이 속한 프로젝트 id.
tabIdstring예대상 탭 id.
fieldstring예집계할 컬럼(필드)명.
aggstring예집계 방식(sum·avg·count 또는 한글 "합계"·"평균"·"개수" 등).
labelstring피벗 헤더에 쓸 표시명(선택).
format"default" | "currency" | "millions" | "percent"표시 형식(선택).
display"value" | "percentRow" | "percentCol" | "percentTotal" | "rank"값 표시 방식(선택).

add_filter ​

변경

탭의 필터 목록에 필터 1개를 추가해요. 같은 field+op 필터가 이미 있으면 새 값으로 교체해요. op: eq(같음)·neq(다름)·in(목록)·range(범위 from~to)·contains(포함)·notContains(미포함)·isNull(NULL)· expr(자유식 — value 에 조건식, 예 매출 > 50 and 지역 = "KR", field 는 빈 문자열). 예: "지역이 서울인 것만" → add_filter({ projectId, tabId, field: "region", op: "eq", value: "서울" }).

ts
add_filter({ projectId: string, tabId: string, field: string, op: "eq" | "in" | "range" | "neq" | "contains" | "notContains" | "isNull" | "expr", value?: unknown, values?: unknown[], from?: unknown, to?: unknown })
인자형식필수설명
projectIdstring예탭이 속한 프로젝트 id.
tabIdstring예대상 탭 id.
fieldstring예필터할 컬럼(필드)명. op=expr 이면 빈 문자열.
op"eq" | "in" | "range" | "neq" | "contains" | "notContains" | "isNull" | "expr"예비교 연산자.
valueunknown단일 값(eq·neq·contains·notContains) 또는 조건식 문자열(expr).
valuesunknown[]값 목록(in).
fromunknown범위 시작(range).
tounknown범위 끝(range).

ts
remove_filter({ projectId: string, tabId: string, field: string })

set_sort ​

변경

그리드 정렬(displayOpts.gridSort)을 설정하거나 해제해요. sortBy=null 이면 정렬을 해제해요. 예: "매출 내림차순 정렬" → set_sort({ projectId, tabId, sortBy: "amount", sortDir: "desc" }). "정렬 해제" → set_sort({ projectId, tabId, sortBy: null }).

ts
set_sort({ projectId: string, tabId: string, sortBy?: string | null, sortDir?: "asc" | "desc" })
인자형식필수설명
projectIdstring예탭이 속한 프로젝트 id.
tabIdstring예대상 탭 id.
sortBystring | null정렬 기준 컬럼. null=정렬 해제.
sortDir"asc" | "desc"정렬 방향(기본 asc).

set_grid_grouping ​

변경

그리드에서 특정 컬럼 기준으로 그룹핑해 보여줘요(displayOpts.gridGroupBy — 컬럼 체크박스가 켜지는 서버사이드 그룹핑). 사용자가 "지역별로 묶어서 보여줘"처럼 그리드에 그룹핑 "표시"를 요청할 때 써요 (채팅 표가 아니라 화면 그리드에 반영). groupBy=[](빈 배열)이면 그룹핑을 해제해요. 예: "지역·분기로 그룹핑해서 보여줘" → set_grid_grouping({ projectId, tabId, groupBy: ["region", "quarter"] }). "그룹핑 해제" → set_grid_grouping({ projectId, tabId, groupBy: [] }).

ts
set_grid_grouping({ projectId: string, tabId: string, groupBy: string[] })
인자형식필수설명
projectIdstring예탭이 속한 프로젝트 id.
tabIdstring예대상 탭 id.
groupBystring[]예그룹핑 기준 컬럼 목록(순서=레벨, 빈 배열=해제).

update_view({ viewId: string, name?: string, visibility?: "workspace" | "private", config?: object })

configobject교체할 분석 구성(TabConfig 전체).

update_widget ​

변경

대시보드 위젯을 수정해요 — 종류(kind=chart|pivot|kpi|table|cohort|heading|text|image|divider)·크기(size)·차트 종류 재정의(chartType)· 배치(position·gridX/gridY/gridW/gridH, 24컬럼)·담긴 페이지(pageId)·콘텐츠 본문(content)·드릴스루(drillthrough). 준 필드만 바뀌고 나머지는 유지돼요. chartType·content·drillthrough 는 null 이 해제다. drillthrough 는 위젯의 한 항목을 클릭했을 때 다른 페이지로 이동하게 해요 — targetPageId 는 list_dashboard_pages 로 얻고, fields 를 주면 그 컬럼의 선택값만 필터로 넘겨요(미지정 = 클릭 지점의 차원 전부). editor 이상(서버 강제). 예1: "이 위젯을 차트로 바꿔줘" → update_widget({ widgetId, kind: "chart" }). 예2: "이 막대를 클릭하면 지역 상세 페이지로 가게 해줘" → update_widget({ widgetId, drillthrough: { targetPageId, fields: ["region"] } }). 예3: "드릴스루 해제해줘" → update_widget({ widgetId, drillthrough: null }).

ts
update_widget({ widgetId: string, kind?: "chart" | "pivot" | "kpi" | "table" | "cohort" | "heading" | "text" | "image" | "divider", size?: string, chartType?: "bar" | "stack" | "bullet" | "pareto" | "radar" | "gauge" | "line" | "stepLine" | "area" | "themeRiver" | "pie" | "doughnut" | "rose" | "treemap" | "sunburst" | "histogram" | "boxplot" | "scatter" | "bubble" | "heatmap" | "parallel" | "funnel" | "waterfall" | "sankey" | "swimlane" | "calendar" | "gantt" | "map" | null, content?: object | null, pageId?: string, drillthrough?: object | null, position?: integer, gridX?: integer, gridY?: integer, gridW?: integer, gridH?: integer })
인자형식필수설명
widgetIdstring예수정할 위젯 id.
kind"chart" | "pivot" | "kpi" | "table" | "cohort" | "heading" | "text" | "image" | "divider"위젯 종류.
sizestring위젯 크기(예: "half"·"full").
chartType"bar" | "stack" | "bullet" | "pareto" | "radar" | "gauge" | "line" | "stepLine" | "area" | "themeRiver" | "pie" | "doughnut" | "rose" | "treemap" | "sunburst" | "histogram" | "boxplot" | "scatter" | "bubble" | "heatmap" | "parallel" | "funnel" | "waterfall" | "sankey" | "swimlane" | "calendar" | "gantt" | "map" | null이 위젯에서만 쓸 차트 종류 재정의. null=해제(저장 보기의 chartType 을 따라요).
contentobject | null콘텐츠 위젯(heading/text/image/divider)의 본문 — text·level·align·src·alt·fit. null=비움.
pageIdstring옮겨 담을 페이지 id(list_dashboard_pages). 같은 대시보드의 페이지만 허용(아니면 404).
drillthroughobject | null드릴스루 설정. null=해제.
positioninteger대시보드 안에서의 배치 순서(작을수록 앞).
gridXinteger그리드 좌표 X(24컬럼, 0~23).
gridYinteger그리드 좌표 Y(행, 0부터).
gridWinteger그리드 너비(24컬럼 기준, 최소 4).
gridHinteger그리드 높이(행, 최소 2 — 1행이면 본문이 0으로 붕괴해요).
