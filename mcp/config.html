분석 구성 ​

탭·보기·대시보드 생성 · 도구 9개

get_tab_config ​

조회

탭의 현재 분석 구성(TabConfig — viewMode·rows·cols·values·filters·pivotOpts·chartOpts·displayOpts)을 돌려줘요. viewMode 는 grid(그리드(원본))·split(분석)·cohort(코호트) 3종이고, 분석의 피벗 표/차트 판은 showPivot/showChart 판 토글로 읽어요(구 저장본은 viewMode "pivot"/"chart" 가 그대로 올 수 있어요 — 각각 분석·표만 / 분석·차트만과 같은 뜻). set_tab_config 로 고치기 전에 현재 상태를 확인할 때 써요. 예: "지금 이 탭 설정 보여줘" → get_tab_config({ projectId, tabId }).

ts
get_tab_config({ projectId: string, tabId: string })
인자형식필수설명
projectIdstring예탭이 속한 프로젝트 id.
tabIdstring예대상 탭 id.

set_tab_config ​

변경

탭의 분석 구성을 부분 patch 해요 — 준 필드만 바뀌고(pivotOpts/chartOpts/displayOpts/cohort 는 필드단위 병합) 나머지는 보존돼요. viewMode·rows·cols·values(집계는 한글 라벨 허용·calc 는 kind:"calc"+expression)·filters·pivotOpts·chartOpts·displayOpts 전체를 다뤄요. 보기 모드 3종: viewMode "grid"=그리드(원본) · "split"=분석(피벗 표·차트 판 — showPivot/showChart 판 토글로 켜고 꺼요; 피벗만=showPivot:true·showChart:false, 차트만=showChart:true·showPivot:false, 판 키가 없는 구 탭에 viewMode:"split" 만 주면 둘 다) · "cohort"=코호트. 구 어휘 viewMode "pivot"/"chart" 는 deprecated — 받으면 split + 판 하나로 정규화돼요. 분석 스위트(이 도구로 전부 조작): ① 지도=chartType:"map"(viewMode:"split", showChart:true, rows 에 지역 차원), ② 퍼널=chartType:"funnel", ③ 코호트/리텐션=viewMode:"cohort" + cohort:{ cohortDateField, entityField, unit:"month"|"week", metric:"retention" }, ④ 시계열 분해=chartOpts:{ trend:{ decompose:true, decomposeLayout:"stack"|"grid" } }(viewMode:"split", showChart:true, 시간축 필요), ⑤ What-if 파라미터=params:[{ id, name, type:"number"|"select", min, max, step, options, default, value }] + calc 측정값 식이 {이름} 으로 참조. 유효 옵션/값은 describe_view_options 로 확인. 예: "지역×분기 매출 피벗으로 만들어줘" → set_tab_config({ projectId, tabId, patch: { viewMode: "split", showPivot: true, showChart: false, rows: ["region"], cols: ["quarter"], values: [{ field: "amount", agg: "합계" }] } }). 예: "지도로 보여줘" → set_tab_config({ projectId, tabId, patch: { viewMode: "split", showChart: true, chartType: "map", rows: ["시도"], values: [{ field: "매출", agg: "합계" }] } }). 예: "코호트 잔존율로 봐줘" → set_tab_config({ projectId, tabId, patch: { viewMode: "cohort", cohort: { cohortDateField: "가입일", entityField: "고객ID", unit: "month" } } }).

ts
set_tab_config({ projectId: string, tabId: string, patch: object })
인자형식필수설명
projectIdstring예탭이 속한 프로젝트 id.
tabIdstring예대상 탭 id.
patchobject예바꿀 필드만 담은 부분 config.

add_dashboard_widget ​

변경

대시보드(프로젝트)에 저장된 보기를 위젯으로 추가해요. kind=chart|pivot|kpi|table|cohort|heading|text|image|divider. kind 는 보기의 표현을 정해요 — chart(차트; 저장 보기의 chartType 이 map/funnel/decompose 등 그대로 반영), pivot(피벗 표), kpi(단일 지표 카드), table(그리드 표), cohort(코호트/리텐션 히트맵; viewMode "cohort" 보기). 지도·퍼널·시계열 분해는 별도 kind 가 아니라 저장 보기의 차트 구성으로 렌더되므로 kind:"chart" 로 추가해요. 개인(private) 보기는 대시보드에 올릴 수 없어요(서버가 거부). 콘텐츠 위젯(heading·text·image·divider)은 저장 보기를 매달지 않으므로 이 도구가 아니라 add_content_widget 으로 추가해요. pageId 를 주면 그 페이지에 담아요(list_dashboard_pages · 미지정 = 기본 페이지). 예: "이 보기를 차트 위젯으로 대시보드에 추가" → add_dashboard_widget({ projectId, savedViewId, kind: "chart" }).

ts
add_dashboard_widget({ projectId: string, savedViewId: string, kind: "chart" | "pivot" | "kpi" | "table" | "cohort" | "heading" | "text" | "image" | "divider", size?: string, pageId?: string, position?: integer })
인자형식필수설명
projectIdstring예대시보드(프로젝트) id.
savedViewIdstring예위젯으로 얹을 저장된 보기 id.
kind"chart" | "pivot" | "kpi" | "table" | "cohort" | "heading" | "text" | "image" | "divider"예위젯 종류(cohort=코호트/리텐션 보기). 콘텐츠 4종은 add_content_widget 으로.
sizestring위젯 크기(예: "half"·"full").
pageIdstring담을 페이지 id(list_dashboard_pages). 미지정 = 기본 페이지.
positioninteger대시보드 안에서의 배치 순서(작을수록 앞).

add_content_widget ​

변경

대시보드에 데이터를 읽지 않는 콘텐츠 위젯을 추가해요 — kind=heading|text|image|divider (heading=제목 한 줄 · text=마크다운 본문 · image=이미지 · divider=구분선). 대시보드를 「보고서답게」 구성할 때(절 제목·설명 문단·로고·구획선) 써요. 콘텐츠 위젯에는 저장된 보기를 연결할 수 없어요 — 보기를 얹는 위젯은 add_dashboard_widget. content 를 생략하면 종류별 기본 본문으로 태어나고, 본문은 서버가 화이트리스트로 살균해요(스크립트·인라인 style 은 버려지고 글자는 남아요). editor 이상(서버 강제). 되돌리려면 remove_dashboard_widget. 예1: "매출 요약 위에 '1. 월간 매출' 제목 넣어줘" → add_content_widget({ projectId, kind: "heading", content: { text: "1. 월간 매출", level: 1 } }). 예2: "이 대시보드 맨 위에 설명 문단 하나 놔줘" → add_content_widget({ projectId, kind: "text", content: { text: "주의 마감 전 잠정치입니다." } }).

ts
add_content_widget({ projectId: string, kind: "heading" | "text" | "image" | "divider", content?: object, pageId?: string, position?: integer })
인자형식필수설명
projectIdstring예대시보드(프로젝트) id.
kind"heading" | "text" | "image" | "divider"예heading=제목 · text=마크다운 본문 · image=이미지 · divider=구분선.
contentobject콘텐츠 본문(종류마다 쓰는 필드가 달라요 · 생략 = 종류별 기본 본문). divider 는 본문이 없어요.
pageIdstring담을 페이지 id(list_dashboard_pages). 미지정 = 기본 페이지.
positioninteger대시보드 안에서의 배치 순서(작을수록 앞).
