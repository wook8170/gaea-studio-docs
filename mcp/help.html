도움말 ​

사용법·정책 · 도구 4개

list_help_topics ​

조회

도움말 지식베이스의 주제 목록(id·제목·요약)을 돌려줘요. 사용법/정책/기능 질문에 앞서 어떤 주제가 있는지 훑을 때. 예: "매뉴얼에 뭐가 있어?" → list_help_topics.

ts
list_help_topics({  })

인자 없음.

get_help_topic ​

조회

도움말 주제 하나의 마크다운 본문(content)을 돌려줘요. list_help_topics/search_help 로 찾은 id 로 조회. 예: "라이브랑 적재 차이 알려줘" → get_help_topic({ topic: "live-vs-extract" }).

ts
get_help_topic({ topic: string })
인자형식필수설명
topicstring예주제 id(파일명, 예: live-vs-extract).

search_help ​

조회

도움말 지식베이스를 키워드/질문으로 검색해 매칭 주제(id·제목·스니펫)를 돌려줘요. 어느 주제를 읽을지 모를 때 먼저 검색. 예: "동기화 주기 어떻게 설정해?" → search_help({ q: "동기화 주기" }).

ts
search_help({ q: string })
인자형식필수설명
qstring예검색어(한글 가능).

get_service_policies ​

조회

서버의 실효 정책값(적재 행수 한도·라이브 정렬 한도·라이브 집계 상한·집계 그룹 상한·에이전트 타임아웃 등)을 실제 설정 기준으로 돌려줘요. "한도가 몇 행이야" 같은 수치 정책은 지어내지 말고 이 도구로 답하라. 예: "적재 한도가 몇 행이야?" → get_service_policies.

ts
get_service_policies({  })
