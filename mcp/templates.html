list_templates ​

조회

설치할 수 있는 업종별 대시보드 템플릿(갤러리) 목록을 돌려줘요 — 각 템플릿의 id·이름·업종(category)·샘플데이터 유무(hasSampleData)·레이아웃(위젯)·필드 시그니처를 담아요. 설치(install_template) 전에 어떤 템플릿이 있는지, mapped 설치에 맞출 필드 이름이 무엇인지 확인할 때 먼저 불러요. 예: "어떤 대시보드 템플릿 있어?" → list_templates({}).

ts
list_templates({  })

인자 없음.

install_template ​

확인 필요(confirm) 변경

갤러리 템플릿을 프로젝트에 설치해요(서버가 데이터소스·보기·위젯을 단일 트랜잭션으로 생성). mode='sample' 이면 새 시뮬레이션 데이터소스를 만들어 그 위에 구경용으로 설치해요(fieldMap 불필요). mode='mapped' 이면 사용자의 기존 endpointId 에 설치하고, 템플릿 필드명을 fieldMap(템플릿필드→내필드)으로 치환해요(endpointId 필수, fieldMap 은 매칭되는 필드만 — 누락 키는 템플릿 이름 유지). 대시보드 개수 한도· 권한(editor 이상)은 서버가 강제해요(초과 시 부분 설치 없이 전체 거부). confirm 없이 부르면 무엇이 생기는지 요약만 반환하고 설치하지 않아요. 예1: "리테일 매출 템플릿을 샘플로 깔아줘" → install_template({ projectId, templateId: "retail-sales", mode: "sample" }) 후 confirm:true. 예2: "이 템플릿을 우리 주문 엔드포인트에 맞춰 설치" → install_template({ projectId, templateId, mode: "mapped", endpointId, fieldMap: { "region": "지역", "amount": "매출액" } }) 후 confirm:true.

ts
install_template({ projectId: string, templateId: string, mode: "sample" | "mapped", endpointId?: string, fieldMap?: object, confirm?: boolean })
인자형식필수설명
projectIdstring예설치 대상 프로젝트 id.
templateIdstring예설치할 템플릿 id(list_templates 의 id).
mode"sample" | "mapped"예'sample'(새 시뮬레이션 데이터소스 위 구경용) 또는 'mapped'(기존 endpointId 에 설치·필드 치환).
endpointIdstringmode='mapped' 일 때 설치 대상 엔드포인트 id(필수).
fieldMapobjectmode='mapped' 필드 치환 맵(템플릿 필드명 → 내 필드명). 누락 키는 템플릿 이름 유지.
