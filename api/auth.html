POST /api/auth/login ​

공개

이메일+비밀번호 로그인

자세히

이메일+비밀번호 로그인. 자동생성/데모 백도어 없음, 임시비번 계정은 mustChangePassword:true. 실패 코드: 401(자격 오류 — 계정 부재·비번 불일치·잠긴 계정에 틀린 비번까지 모두 같은 범용 문구) · 403(IP 허용목록) · 423 Locked(비밀번호는 맞지만 계정 잠김 — 남은 시간 또는 관리자 해제 안내를 error 문장으로) · 429(rate limit, Retry-After) · 503(LDAP 연결 장애)

요청 본문 application/json · 모델 PostAuthLoginRequest

emailstring필수email
passwordstring필수1자 이상

응답

  • 200성공했어요
  • 401로그인하지 않았거나 토큰이 만료됐어요
  • 429너무 자주 불렀어요 — Retry-After 초 뒤에 다시 불러요
  • 503지금은 처리할 수 없어요 — 잠시 뒤 다시 불러요

성공 응답 필드: mustChangePasswordmustSetupTotplicensedeploymentProfile 외 더 있음

호스트 자동 연동 (키트 자동 회전 pull) — { autoRotatePull: boolean } → { id, autoRotatePull }. embed 키만(그 외 404) · 사이트 내부 키(링크·SSO)는 404 · PAT/provisioning 은 403(세션 전용) · 감사 EMBED_KEY_AUTO_ROTATE_ON/_OFF. 켜면 키트가 POST /bi-connect/rotate 로 자기 서명 비밀을 스스로 교체할 수 있어요(기본 off)
