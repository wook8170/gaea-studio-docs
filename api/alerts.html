모달 측정값 선택

자세히

모달 측정값 선택 — fields[] = 보기 설정(config.values)의 측정값 전부({ field: '<필드>__<집계 canonical>', label: '필드라벨 (집계)'(사용자 지정 label 우선), value: number \| null }, 설정 순서 · 열 축·표시 모드·집계 종류 무관 · 모르는 집계·빈 필드는 제외 · 요청자 기준 마스킹 컬럼 제외). value 는 피벗 집계 표의 컬럼 합산이고 못 읽으면 null(라이브 인메모리 경로가 null 로 접는 중앙값·표준편차·고유 개수·백분위 등 — 화면 «현재값 없음»). 표 조회 자체가 실패하면 200 + 후보 그대로(값 null) + valueError(축약 문장) — 후보를 잃지 않아요(종전엔 헤더 중 수치 컬럼만 후보라 값이 없는 측정값이 목록에서 빠졌어요). 후보 조립 자체의 실패만 502 + 축약 문장(커넥터 원문 예외 비노출 — classifyExportFailure)
