실시간 데이터 ingest…

자세히

실시간 데이터 ingest(bodyLimit ingestBodyLimit() · 시간창 rate-limit ingestRateConfig() 기본 600회/60초 → 429 ingest-rate-limited + Retry-After)

파라미터

이름위치형식설명
id 필수경로string엔드포인트 ID

요청 본문 application/json · 모델 PostEndpointsIdIngestRequest

rowsobject[]필수

응답

  • 200성공했어요
  • 401로그인하지 않았거나 토큰이 만료됐어요 — unauthorized
  • 403권한이 없어요(역할 · 토큰 범위 · 읽기 전용 토큰 · 임베딩 주소) — ingest-key-required, resource-scope-required, resource-scope
  • 404엔드포인트를 찾지 못했어요 — endpoint not found
  • 409지금 상태와 맞지 않아 처리하지 못했어요 — realtime-not-push, realtime-tsfield-missing
  • 413보낸 데이터가 너무 커요 — too-many-rows
  • 422요청은 맞지만 지금은 처리할 수 없어요 — realtime-tsfield-invalid, realtime-ingest-invalid-ts
  • 429너무 자주 불렀어요 — Retry-After 초 뒤에 다시 불러요 — ingest-rate-limited, buffer-full

성공 응답 필드: accepteddroppedrowPolicy

오류 본문은 { "error": "코드", "message": "설명" } 형태예요.

curl -X POST 'https://gaea.example.com/api/endpoints/{id}/ingest' \
  -H "Authorization: Bearer $GAEA_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "rows": [
    {
      "ts": "2026-10-09T09:00:00Z",
      "sensor": "A-1",
      "value": 21.5
    }
  ]
}'
