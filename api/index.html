REST API ​

외부 시스템이 Gaea Studio 와 연동할 때 쓰는 REST API 예요. 모든 경로는 /api 아래에 있고, 본문은 JSON 이에요.

인증은 Authorization: Bearer <토큰> 한 가지예요. 연동 프로그램은 개인 액세스 토큰(gpat_ 로 시작)을 쓰고, 스튜디오 「내 정보 › 개인 액세스 토큰」에서 발급해요.

인증 시험 모드가 켜진 서버에서는 6개 기능의 API 가 403 feature_hidden 으로 막혀요.

공개 연동 API 249개와 관리자 API 81개를 실었어요(서버에 등록된 라우트 466개 중 스튜디오 화면 내부용을 뺀 수예요). 원본 명세 파일은 openapi.json 으로 내려받을 수 있어요.

인증 ​

sh
curl -H "Authorization: Bearer gpat_xxxxxxxxxxxxxxxxxxxx" https://gaea.example.com/api/auth/me
표기의미
공개인증 없이 불러요. 로그인 · 공유 링크처럼 로그인 전 단계이거나, 토큰 자체가 자격인 경로예요.
로그인 세션 · 개인 액세스 토큰 · 임베딩 키Authorization: Bearer <토큰> 으로 불러요. 로그인 세션 토큰, 개인 액세스 토큰(gpat_), 서명한 임베딩 토큰(gset_)을 모두 받아요. 워크스페이스 역할은 서버가 다시 확인해요.
로그인 세션만브라우저 로그인 세션으로만 불러요. 액세스 토큰으로 토큰 · 세션 · 2단계 인증을 관리하지 못하게 막아요.
로그인 세션 · 프로비저닝 키워크스페이스 키를 관리하는 경로예요. 로그인 세션이나 프로비저닝 키만 받고, 다른 액세스 토큰은 거절해요.
플랫폼 관리자플랫폼 관리자로 등록된 계정만 불러요.
내 PC 연결용 액세스 토큰내 PC 의 CLI 연결 프로그램이 쓰는 전용 액세스 토큰만 받아요.
BI 빌더 사용 + 로그인관리자가 BI 빌더를 켠 서버에서 로그인 세션이나 액세스 토큰으로 불러요.
