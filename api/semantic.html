GET /api/datasources/:id/catalog ​

로그인 세션 · 개인 액세스 토큰 · 임베딩 키

그 데이터소스 하위 전체(자기 + 엔드포인트 + 필드)의 카탈로그 항목을 1회 조회

자세히

그 데이터소스 하위 전체(자기 + 엔드포인트 + 필드)의 카탈로그 항목을 1회 조회 — 편집 화면(DataCatalogModal)이 한 번에 필요한 집합이에요. 응답 { dataSourceId, entries[] }, 각 항목 { targetType:'datasource'\|'endpoint'\|'field', dataSourceId?\|endpointId?, fieldName?, description, tags[], stewardUserId, stewardName, updatedAt }
