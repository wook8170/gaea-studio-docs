PUT /api/admin/settings/map ​

플랫폼 관리자 인증 시험 모드에서 차단

지도 배경 설정 저장…

자세히

지도 배경 설정 저장 — { basemap: bundled\|none\|osm\|vworld\|xyz\|style\|null, tileUrl?, styleUrl?, vworldMode?, vworldKey? }. basemap: null = 지도 설정 키 전부 삭제(기본값으로). 타일 주소는 https + {z}/{x}/{y} 필수, VWorld 공식 WMTS 는 {key} 자리와 인증키 필수, 스타일 주소는 https — 위반은 400 invalid_map_settings(사유 문장). airgap 에서 osm·vworld 는 403 profile_restricted(feature: map-online-basemap). vworldKey 는 생략=유지 · ''=삭제 · 값=암호화 저장(credentials.ts). 감사 UPDATE_MAP_SETTINGS(키 원문 없음)

요청 본문 application/json · 모델 PutAdminSettingsMapRequest

basemapenum필수null 가능
tileUrlstring2048자 이하
styleUrlstring2048자 이하
vworldModeenum"keyless" · "wmts"
vworldKeystring128자 이하

응답

  • 200성공했어요
  • 400보낸 값이 맞지 않아요 — invalid_map_settings
  • 401로그인하지 않았거나 토큰이 만료됐어요 — unauthorized
  • 403권한이 없어요(역할 · 토큰 범위 · 읽기 전용 토큰 · 임베딩 주소)

오류 본문은 { "error": "코드", "message": "설명" } 형태예요.

curl -X PUT 'https://gaea.example.com/api/admin/settings/map' \
  -H "Authorization: Bearer $GAEA_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "basemap": "bundled"
}'
