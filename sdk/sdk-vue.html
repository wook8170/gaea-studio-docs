@gaea/grid-sdk-vue ​

버전 0.1.0-alpha.0 · 공개 export 252개

Vue 3 용 컴포넌트예요. React 컴포넌트를 Veaury 로 감싸 같은 기능을 써요.

설치 ​

sh
pnpm add @gaea/grid-sdk-vue @gaea/grid-sdk-react @gaea/grid-tokens \
         @gaea/glide-data-grid @mantine/core \
         vue veaury react@^19.2 react-dom@^19.2 \
         lodash marked@^16 react-responsive-carousel
pnpm add -D @types/react @types/react-dom

선택 기능을 쓸 때 더 설치해요.

sh
pnpm add echarts
pnpm add exceljs

안내(README) ​

@gaea/grid-sdk-react 의 React 컴포넌트를 Veaury 로 호스팅한 Vue 3 래퍼입니다. 1:1 포팅이 아닙니다 — 2026-09-12 실측으로 sdk-react 는 52 개 서브패스에 걸쳐 런타임 value export 376 종, 이 패키지는 2 개 서브패스에 114 종(30.3 %)입니다. 여기 없는 필터·피벗 보조 UI·툴바 슬롯·React 훅은 @gaea/grid-sdk-react 에서 직접 import 하세요(필수 peer 라 이미 설치되어 있습니다). 목록은 src/index.ts 상단 주석.

사설 레지스트리 설치 ​

@gaea/* 는 상용 · 비공개(restricted) 스코프입니다. 공개 npm 레지스트리에는 없으며, 계약된 사설 레지스트리에 인증한 뒤에만 설치됩니다. 레지스트리 URL 은 저장소에 커밋하지 않습니다 — 환경마다 .npmrc 로 지정하세요.

ini
# 프로젝트 루트 .npmrc  (또는 ~/.npmrc)
@gaea:registry=https://<your-registry>/
//<your-registry>/:_authToken=${GAEA_NPM_TOKEN}
sh
# CI 에서는 환경변수로도 됩니다
export NPM_CONFIG_@GAEA:REGISTRY="https://<your-registry>/"

배포 tarball 에는 컴파일된 dist 만 들어갑니다 — TypeScript 원본과 소스맵은 포함되지 않습니다(files: ["dist","LICENSE","NOTICE","NOTICE.md","README.md"], sourcemap: false). 타입은 dist/**/*.d.ts 로 제공됩니다.

설치 ​

sh
pnpm add @gaea/grid-sdk-vue @gaea/grid-sdk-react @gaea/grid-tokens \

@mantine/core 9.x 가 react ^19.2 를 요구하므로 이 패키지의 peer 도 react ^19.2.0 입니다. React 19 용 veaury 설정(createRoot)은 이 패키지가 첫 컴포넌트를 브리지하기 전에 스스로 하므로 main.ts 에 setVeauryOptions 를 쓸 필요가 없습니다. 배포 tarball 에는 CHANGELOG.md 가 함께 들어갑니다.

ts
// 스타일은 한 줄 — sdk-react 의 dist/style.css 가 glide-data-grid 코어 CSS · Mantine CSS · 토큰 CSS 를 안에서 @import 한다
// (sdk-vue 는 sdk-react 를 React 호스트로 사용하므로 같은 파일을 쓴다)
import "@gaea/grid-sdk-react/style.css";

@gaea/grid-sdk-vue 는 자체 스타일시트를 내보내지 않습니다. 모든 SFC 가 @gaea/grid-sdk-react 컴포넌트를 호스팅하므로 CSS 정본은 sdk-react 한 벌이고, sdk-vue src 에는 <style> 블록이 0 개라 빌드가 dist/style.css 를 만들지 않습니다. 이전 문서가 안내하던 @gaea/grid-sdk-vue/style.css 는 존재한 적 없는 파일이라 exports 에서 제거했습니다.

Plugin 설치 (전역) ​

ts
// main.ts
import { createApp } from "vue";
import App from "./App.vue";
import GaeaGridSdkVue from "@gaea/grid-sdk-vue";

const app = createApp(App);
app.use(GaeaGridSdkVue);
app.mount("#app");

이후 컴포넌트는 글로벌 등록되어 <DataGrid />, <PivotGrid /> 등으로 바로 사용 가능합니다.

5 분 Quick Start ​

vue
<script setup lang="ts">
import {
  DataGrid,
  ThemeProvider,
  type Column,
} from "@gaea/grid-sdk-vue";
import { inMemoryDataSource } from "@gaea/grid-sdk-core";

const columns: Column[] = [
  { id: "name", title: "이름", width: 160 },
  { id: "qty", title: "수량", width: 100, kind: "number" },
  { id: "price", title: "가격", width: 120, kind: "money" },
];

const dataSource = inMemoryDataSource({
  rows: [
    { id: 1, name: "Acme A", qty: 10, price: 1200 },
    { id: 2, name: "Acme B", qty: 25, price: 980 },
  ],
});
</script>

<template>
  <ThemeProvider mode="auto">
    <DataGrid
      :columns="columns"
      :data-source="dataSource"
      :editing="{ mode: 'excel' }"
      :sort="{ multi: true }"
    />
  </ThemeProvider>
</template>

⚠ 타입 노트 — Vue SFC 컴파일러는 sdk-react 의 cross-package generic prop 타입을 추출하지 못합니다. 래퍼 SFC 의 defineProps<Props>() 는 빈 인터페이스로 선언하고 모든 prop 은 useAttrs() 로 forward 합니다. TypeScript 호출 측에서 strict typing 이 필요하면 sdk-react 의 prop 타입 (예: GridToolbarProps, PivotGridProps) 을 import 해서 cast 하세요. <DataGrid> 만 generic row 타입을 그대로 노출합니다.

Veaury 호스팅 — 작동 원리와 비용 ​

본 패키지는 React 컴포넌트를 그대로 다시 구현하지 않고 Veaury 의 applyReactInVue 로 React 트리를 Vue 컴포넌트로 감쌉니다. 이로 인해:

  • 장점 — React / Vue 두 패키지가 동일 코드베이스 (sdk-react) 에서 출발하므로 버그 수정 / 신규 기능이 양쪽에 자동 반영됩니다. props / events / slots 가 1:1.
  • 번들 비용 — Vue 만 사용하더라도 React + ReactDOM + Veaury bridge 가 추가됩니다.
    • React 19 (production min+gzip): ~7 kB
    • ReactDOM 19 (production min+gzip): ~33 kB
    • Veaury bridge: ~3 kB
    • 합계 ~ 43 kB gzip (런타임), tree-shake 후 코드 분할 가능.
  • SSR — 현재는 client-only. Nuxt 사용 시 <ClientOnly> 로 감싸세요.
vue
<template>
  <ClientOnly>
    <DataGrid :columns="columns" :data-source="dataSource" />
  </ClientOnly>
</template>
