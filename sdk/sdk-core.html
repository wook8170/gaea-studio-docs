@gaea/grid-sdk-core ​

버전 0.1.0-alpha.0 · 공개 export 470개

표 · 피벗 · 차트 계산과 데이터 연결, 내보내기를 담은 화면 무관 모듈이에요.

설치 ​

sh
pnpm add @gaea/grid-sdk-core

안내(README) ​

Framework-agnostic 코어 — Pivot Engine · Sync Store · DataSource · Export · Chart model/adapter. React / Vue / vanilla 어디서든 import 해서 사용할 수 있는 순수 TS 모듈입니다.

사설 레지스트리 설치 ​

@gaea/* 는 상용 · 비공개(restricted) 스코프입니다. 공개 npm 레지스트리에는 없으며, 계약된 사설 레지스트리에 인증한 뒤에만 설치됩니다. 레지스트리 URL 은 저장소에 커밋하지 않습니다 — 환경마다 .npmrc 로 지정하세요.

ini
# 프로젝트 루트 .npmrc  (또는 ~/.npmrc)
@gaea:registry=https://<your-registry>/
//<your-registry>/:_authToken=${GAEA_NPM_TOKEN}
sh
# CI 에서는 환경변수로도 됩니다
export NPM_CONFIG_@GAEA:REGISTRY="https://<your-registry>/"

배포 tarball 에는 컴파일된 dist 만 들어갑니다 — TypeScript 원본과 소스맵은 포함되지 않습니다(files: ["dist","LICENSE","NOTICE","NOTICE.md","README.md"], sourcemap: false). 타입은 dist/**/*.d.ts 로 제공됩니다.

Quick Start — Pivot ​

ts
import { pivot, builtInAggregators } from "@gaea/grid-sdk-core";

const rows = [
  { region: "동", product: "A", qty: 10, revenue: 100 },
  { region: "동", product: "B", qty: 20, revenue: 250 },
  { region: "서", product: "A", qty: 30, revenue: 320 },
  { region: "서", product: "B", qty: 25, revenue: 280 },
];

const result = pivot(rows, {
  rows: ["region"],
  cols: ["product"],
  values: [
    { field: "revenue", agg: "sum" },
    { field: "qty", agg: "sum" },
  ],
  subtotals: { rows: true, cols: true, grand: true },
});

console.log(result.matrix);     // 2D cell matrix
console.log(result.rowTree);    // hierarchical row tree
console.log(result.totals);     // grand total

Quick Start — Sync Store ​

ts
import { createStore, selectorOf } from "@gaea/grid-sdk-core";

type State = { selection: number[]; filter: string };

const store = createStore<State>({ selection: [], filter: "" });

const filterSelector = selectorOf(store, (state) => state.filter);

const unsub = filterSelector.subscribe(
  () => console.log("filter changed:", filterSelector.getSnapshot()),
);

store.setState((prev) => ({ ...prev, filter: "ACME" }));
unsub();

Quick Start — DataSource + tx queue ​

ts
import {
  restDataSource,
  createTxQueue,
  createOptimisticBuffer,
} from "@gaea/grid-sdk-core";

type Order = { id: string; name: string; amount: number };

// 1. 데이터 소스
const ds = restDataSource<Order>({
  url: "/api/orders",
  fetchFn: fetch,
});

// 2. tx queue — 편집을 큐잉, 배치 commit
const tx = createTxQueue(ds, {
  flushDebounceMs: 200,
  retryCount: 3,
});

// 3. optimistic buffer — UI 즉시 반영 + 실패 시 rollback
const opt = createOptimisticBuffer<Order>();
const handle = opt.apply("1", "name", "Old Corp", "Acme Corp");

tx.enqueueUpdate("1", "name", "Old Corp", "Acme Corp");
const result = await tx.flush(); // 실서버 commit
if (result?.failed.length) {
  handle.rollback();
  await tx.retryFailed("1", "name");
} else {
  handle.confirm();
}

브라우저 전역 fetch를 자동으로 쓰는 편의 wrapper가 필요하면 @gaea/grid-sdk-core/data-source/browser의 browserRestDataSource()를 사용합니다. runtime-neutral core API는 fetchFn을 명시 주입합니다.

DataGrid handle이나 custom toolbar에서 datasource 명령만 공유해야 할 때는 createDataSourceCommandAdapter()를 사용해 flushDataSource()와 retryFailed()를 같은 headless command path로 묶습니다.

Quick Start — Grid data pipeline ​

ts
import {
  applyGridSortRules,
  applyToolbarFilters,
  buildGridColumnIndex,
  computeGridMergeRegions,
} from "@gaea/grid-sdk-core/grid/data-pipeline";

const columns = [
  { id: "region", field: "region", dataType: "string" },
  { id: "amount", field: "amount", dataType: "number" },
] as const;

const columnsById = buildGridColumnIndex(columns);
const filtered = applyToolbarFilters(
  rows,
  [{ field: "region", op: "eq", value: "EAST" }],
  "atlas",
  columnsById,
);
const sorted = applyGridSortRules(filtered, [{ column: "amount", direction: "desc" }], columnsById);
const merges = computeGridMergeRegions(sorted, { scope: "value", columns: ["region"] }, columnsById);

React keeps deprecated compatibility helpers such as applySortRules() at the root package, but new headless code should import the core data-pipeline helpers directly.

Subpath imports ​

전체 import 외에 모듈 단위 subpath 가 필요하면 다음 path 패턴을 사용하세요 (tree-shaking 은 이미 sideEffects: false + ESM-only 로 잘 동작합니다).

ts
// 단일 모듈 import
import { pivot } from "@gaea/grid-sdk-core";
import { writeCsv } from "@gaea/grid-sdk-core";
import { createStore } from "@gaea/grid-sdk-core";

본 패키지는 ESM-only 입니다 ("type": "module"). CJS host 에서는 dynamic import() 또는 tsup/vite/webpack 5+ 의 ESM interop 을 사용하세요.
