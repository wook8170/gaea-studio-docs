안내(README) ​

glideapps/glide-data-grid 의 Canvas 렌더러를 호스트로 사용하는 React SDK. RealGrid2 / RealPivot2 / AG Grid 의 주요 기능을 단일 통합 API + 디자인 토큰 기반 테마 + DB 영속화 (DataSource) 로 묶었습니다.

사설 레지스트리 설치 ​

@gaea/* 는 상용 · 비공개(restricted) 스코프입니다. 공개 npm 레지스트리에는 없으며, 계약된 사설 레지스트리에 인증한 뒤에만 설치됩니다. 레지스트리 URL 은 저장소에 커밋하지 않습니다 — 환경마다 .npmrc 로 지정하세요.

ini
# 프로젝트 루트 .npmrc  (또는 ~/.npmrc)
@gaea:registry=https://<your-registry>/
//<your-registry>/:_authToken=${GAEA_NPM_TOKEN}
sh
# CI 에서는 환경변수로도 됩니다
export NPM_CONFIG_@GAEA:REGISTRY="https://<your-registry>/"

배포 tarball 에는 컴파일된 dist 만 들어갑니다 — TypeScript 원본과 소스맵은 포함되지 않습니다(files: ["dist","LICENSE","NOTICE","NOTICE.md","README.md"], sourcemap: false). 타입은 dist/**/*.d.ts 로 제공됩니다.

5 분 Quick Start — DataGrid ​

tsx
import {
  DataGrid,
  type Column,
} from "@gaea/grid-sdk-react";
import { ThemeProvider } from "@gaea/grid-sdk-react/theme";
import { inMemoryDataSource } from "@gaea/grid-sdk-core";

const columns: Column[] = [
  { id: "name", title: "이름", width: 160 },
  { id: "qty", title: "수량", width: 100, kind: "number" },
  { id: "price", title: "가격", width: 120, kind: "money" },
  { id: "active", title: "활성", width: 80, kind: "boolean" },
];

const dataSource = inMemoryDataSource({
  rows: [
    { id: 1, name: "Acme A", qty: 10, price: 1200, active: true },
    { id: 2, name: "Acme B", qty: 25, price: 980, active: false },
  ],
});

export function MyGrid() {
  return (
    <ThemeProvider mode="auto">
      <DataGrid
        columns={columns}
        dataSource={dataSource}
        editing={{ mode: "excel" }}
        sort={{ multi: true }}
        footer={{ rows: [{ aggregations: { qty: "sum", price: "avg" } }] }}
      />
    </ThemeProvider>
  );
}

이 설정만으로:

  • 다중 컬럼 정렬 (Shift+Click 으로 secondary key)
  • Excel 키맵 편집 (Tab/Shift+Tab/Enter/F2/Esc/Delete)
  • 합계 footer 자동 계산
  • 디자인 토큰 라이트/다크 자동 분기 (mode="auto" 는 prefers-color-scheme 따름)

가 즉시 동작합니다.

성능 / 호환성 ​

  • Canvas 렌더 — glide-data-grid 의 single-pass canvas 가 1M+ rows 까지 부드러운 스크롤.
  • React 19.2+ (react, react-dom peer ^19.2.0 — 필수 peer @mantine/core 9.x 가 요구하는 하한과 일치. React 18 은 Mantine 9 peer 위반이라 지원하지 않습니다).
  • 모든 컴포넌트는 controlled / uncontrolled 양쪽 운용. DataSource 만 줘도 자동으로 편집 → tx queue → optimistic buffer → 서버 commit 흐름이 동작.
